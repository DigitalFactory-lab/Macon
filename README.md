# Déclic Chantier — Atelier Maçon

Dépôt destiné au site pédagogique de la Digital Factory.

## État du déploiement

Les fichiers du site n'ont pas encore été transférés dans ce dépôt. L'archive source à utiliser est `Macon-site-sans-video.zip` (32 fichiers), préparée à partir de `Declic-Chantier-site-local(2).zip`.

Pour déployer le site, placer à la racine les fichiers `index.html`, `app.js`, les fichiers CSS et les autres pages, ainsi que le dossier `assets/`. Ajouter séparément `assets/impression-3d-beton.mp4`.

Ensuite activer GitHub Pages sur la branche `main`, dossier `/ (root)`.
